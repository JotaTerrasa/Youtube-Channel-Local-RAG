# Offline Fixture Walkthrough

This small walkthrough makes one part of the implementation observable without
starting Docker or contacting an external service:

```bash
python scripts/offline_fixture_demo.py
```

It creates a temporary, **synthetic** cached record and sends it through the
same `IngestPipeline` cached-transcript branch used by the app. That branch
calls `yt_agent.chunking.build_chunks` and passes the resulting chunks to the
knowledge-base adapter.

The fixture is explicitly not a YouTube video or a real transcript. It does
not download a video, transcribe audio, start ChromaDB, create embeddings, or
call Ollama. The example therefore demonstrates cache handling, chunking, and
timestamped provenance only—not an end-to-end RAG answer.

Expected output:

```text
Offline fixture demo — reproducible and local-only
Fixture: synthetic test data; not a YouTube video or real transcript.
External services used: none (no YouTube, Whisper, Chroma, embeddings, or Ollama).
Cached pipeline result: cached; chunks passed to the adapter: 1.
Timestamped source metadata generated by yt_agent.chunking.build_chunks:
[1] 0:00-0:24 https://example.invalid/youtube-rag-offline-fixture?t=0s
```

For the full local flow (real YouTube ingestion, Whisper, ChromaDB, embeddings,
and Ollama), follow the setup in the [README](../README.md).
